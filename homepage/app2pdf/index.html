On request APP2PDF (TicketSwap)

Turns an app-only Czech soccer ticket into a PDF you can resell on TicketSwap.

Since the 2026/27 season, most Czech clubs and the Czech soccer association have been fighting ticket fraud by delivering tickets only to a mobile app (Sparta, Slavia, Fotbal+). There is no PDF ticket, the QR code appears in the app only shortly before the match, and screenshots are blocked.

Ticketmaster, for example, already uses this model. Forwarding a ticket inside the app is still allowed, so TicketSwap has partnered with Ticketmaster to let a seller upload such a "ticket" and then tell them how to forward it. No Czech club is integrated yet; TicketSwap's official support says their integration is in the pipeline.

TicketSwap uses sophisticated methods to verify that a PDF is genuine. Even so, there is a way to get the QR code from the app into a PDF that TicketSwap accepts, and the holder of that ticket can enter the stadium with it.

Clubs supported so far:

  • Slavia

Although TicketSwap does enough to verify its users, this project will never be public, because it would make it a little easier to commit the very fraud the clubs are trying to prevent.
